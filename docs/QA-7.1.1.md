The build freezes application/native/test inputs, runs the gates, compiles production Java, verifies DEX/assets/manifest/signature/alignment, and rejects debuggable/test-only/instrumentation game deliveries.

- Actual-control mayor journey: deed, disconnected fishery, painted road connection, wharf/housing/clinic/grocer, live crews/cargo, service funding, inspection and archive round trip.

- Reliability: chronology/quota/corruption/transaction/stale-callback tests; bounded rapid saves; large archives; legacy grid/schema migration; repeated UI, focus, contrast, motion/audio and cache invalidation.
- Android host: official SDK compilation plus nine actual API30 instrumentation checks using unchanged production Java and a lightweight same-origin page. These cover save failure/timeout/stale acknowledgements, actual renderer termination, native recovery/recreation and retained storage. They use programmatic framework actions.

## Limits

Physical-device FPS/thermals, full-game physical touch and system document-picker/provider flows have not been certified. The full native game rendered successfully in an older Chrome83 WebView, but software-emulator SystemUI ANRs prevented a complete native play session. The later native host harness isolates recovery behavior from that heavy workload. No claim of exhaustive bug removal, calibrated economic forecasting or commercial art parity is made.

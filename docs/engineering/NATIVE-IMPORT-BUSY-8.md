# Native import feedback and duplicate-operation guard

The Android wrapper now retains the READ operation until renderer restore acknowledgement, shows a non-cancellable native “Restoring town…” message before file reading and validation, and blocks Back plus new bridge archive requests until completion. Two native frames and two renderer frames allow feedback to paint before synchronous validation; a matching renderer overlay also keeps the operation labelled. No percentage or mid-validation cancellation is promised. Renderer completion removes the overlay and acknowledges success/failure; failure, renderer loss and Activity destruction release native busy UI. Focus returns to the WebView. The model's existing atomic hydrate boundary remains unchanged.

It then sends an Android Back key and two native archive-open bridge requests during the operation: exactly one restore invocation occurs, result validates, request/busy state clears, focus returns. A later malformed archive releases busy state and preserves the complete serialized old town exactly. No raw save or key is published. The test builder's existing embedded-game hash guards are preserved, and ImportBusyHarness is forbidden in ordinary packaged APK verification.

Synchronous import still costs time; this change provides truthful blocking feedback and prevents competing operations. Activity/renderer loss recovery retains the existing last completed save contract. No physical-device performance or current modern-Android certification is claimed.

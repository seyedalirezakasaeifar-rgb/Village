## Transient/external effects to checkpoint or delay

Check **rngState**, not only G.rngState. Other state outside G includes migrationRecent/session counters/owner, construction crewDay/crewsUsed/regionalCrews, marketOpen and day-local books, graph/building/urban/transit caches and captured object references, traffic/visual state, UI selection/pendingEvent/drafts/roadPainted. Prefer refusal before touching them; if rollback is used, restore or invalidate explicitly. Rejected commands must not turn stale quotes into valid references to abandoned objects.

`save`, persistSnapshot, pending asynchronous/local/native writes and save epoch/order/revision/town are external durability effects: canceling a later continuation cannot retract an already issued write. Current mission/event/helper paths save internally, and the production frame does not establish simulationBusy around tick. Emit persistence only for admitted complete state, with an explicit policy for a rejected day and Back/suspend/export. Audio/click feedback can remain immediate and truthful; it is not an economic asset and need not be rolled back. Avoid turning an error/refusal into a success toast or consumed unretryable modal.

## Acceptance checklist for the owner design

- [ ] All roots above participate, including direct householdFormation, bank branch creation, ordinary daily/history/claim growth and non-identity public commands. Initialization and creator guards are separate from daily admission.
- [ ] Refusal preserves accounts/commodities, RNG, day/date, IDs, rosters, work/escrow/title/cargo and persistent history. A documented normal economic deferral is distinct from capacity refusal. Error/result contracts are consistent through every caller.
- [ ] No failed day or command writes persistence or advertises success; last completed state remains exportable/importable with native and browser budgets. Fault immediately before/after every debit, append, escrow conversion and queued persistence boundary.
- [ ] Active/history count categories, shared UTF8 wire/logical bytes, nodes/cells/depth and initialization reserve are covered. No deleting identities/claims or raising limits to make an action fit.
- [ ] Cheap ordinary case: a measured conservative reservation/headroom/version fast path; avoid full encode/decode, deep clone or per-read proxy traps at every leaf. Exact near-capacity checks occur at bounded command/day boundaries; leaf calls inside an admitted outer operation do not repeatedly serialize the city. Measure normal founding and representative late-city whole-day cost, not only empty helper time.
- [ ] Re-run actual paid controls and actual birth/formation/completion/loan/default/dispatch boundaries at one-byte/count/cell headroom; add repeated-click/refusal/retry and exact continuation tests. The supplied null/throw probes locate caller hazards but do not certify an actual byte-limit guard.

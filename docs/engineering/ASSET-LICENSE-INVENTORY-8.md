# Asset and license inventory

This inventory records repository evidence, not a blanket rights clearance. It covers the current tree at the time of review.

## Explicit project licenses

- **Project source and original game assets:** root [`LICENSE`](../../LICENSE) applies the MIT License, copyright 2026 Townledger contributors, and explicitly says bundled third-party software and fonts retain their own licenses.
- **Original soundtrack:** [`assets/music/LICENSE.txt`](../../assets/music/LICENSE.txt) dedicates the ten compositions, recordings, and score-generation code under CC0-1.0. It says the pieces are original and use no external samples or borrowed recordings. [`assets/music/score.json`](../../assets/music/score.json) records the ten tracks and their asset hashes.
- **Original synthesized sound effects:** [`assets/sound/LICENSE.txt`](../../assets/sound/LICENSE.txt) says the effects were created for this project and are licensed under the project MIT license.
- **Graphics:** the root MIT license covers project source and assets. The checked-in art implementation is procedurally drawn by application code: [src/65-landscape.js](../../src/65-landscape.js) identifies its code-native pixel art; [src/60-renderer.js](../../src/60-renderer.js), [src/68-living-art.js](../../src/68-living-art.js), [src/68-transit-art.js](../../src/68-transit-art.js), [src/69-civic-materials.js](../../src/69-civic-materials.js), [src/98zz-diorama.js](../../src/98zz-diorama.js), and the other `src/*art*.js`, `src/*diorama*.js`, and `src/*district-life*.js` modules draw scenery and actors with Canvas primitives. [src/98zzzzzzzzz-region-locator.js](../../src/98zzzzzzzzz-region-locator.js) draws the regional locator with an inline SVG string. The `assets/` and `android/` filename scan found no imported raster/vector artwork files; the Android launcher icon is a checked-in vector XML at [android/res/drawable/townledger.xml](../../android/res/drawable/townledger.xml). Repository history shows successive authored procedural-art changes, including commits `a8ecec8`, `5df54fa`, and `b914b51`. This supports that shipped game scenery is generated from repository code rather than imported art files. Individual authorship for every historical code contribution is not separately inventoried.

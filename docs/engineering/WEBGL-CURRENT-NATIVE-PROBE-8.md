# Isolated Newfoundland WebGL native probe

Composite includes accepted public model 669c908706af997375680674390e46fd132a970a in full. The only source modules changed relative to that model are the new read-only WebGL adapter, optional transit visual time/zoom parameters, and region-locator camera hooks. No economic kernel was substituted. District-driven family semantics are now enabled from the independently accepted model descriptor. A transient O(1) observer of its existing invalidateUrban transaction boundary joins the visual revision; it never mutates archives or recomputes demographics. The same-day paid deposit test verifies refresh, stable cached reads, exact descriptor equality, total-money conservation and partial-day guard. The earlier 01da3f1 probe kept this gate disabled.

Build: `python tools/assemble.py`. Serve the complete `assets` directory over the existing supported HTTP/native asset origin. Open `index.html?cityArt=webgl`; default URL retains Canvas. Three 0.160.1 and MIT license are bundled locally. No CDN/network asset dependency. On WebGL module/context/shader failure the renderer releases resources and returns to Canvas.

Minimal reproducible fixture: New Town using ordinary #newTown control, pause with #pause, close Town Hall with #panelClose. Drag pans, wheel/pinch zooms, plus/minus/centre and regional locator act on the 3D camera. Resize portrait and verify canvas/annotation align and the same projected Hall remains pickable. Overview fits all four atlas corners, including portrait. Existing Public Works Road tool dispatches original construction and refreshes the same renderer/context. Save uses existing storage; Continue must restore state. No test helper is needed for manual probe.

Validated on host Chromium: DPR1/2/3 at 1280x720,390x844,844x390; near/mid/far actual Hall picks, archive/RNG invariance and save. Far tier invokes zero individual actor sources. Night uses actual evening option, occupied/open-state warm glazing and existing streetlamp locations. Overlays use real model values with symbols/outlines, actual transit routes and parcel boundaries. Camera streaming and GPU cleanup are bounded; actual road cargo, paid transit and boats retain simulation IDs. No invented economic traffic.

Limitations: production activation is NOT proposed by this probe. SwiftShader remains severely slow (previous same-scene full-frame medians roughly389ms at1280x720 despite15 calls); CPU submission is not FPS. Native API30/WebView83 software emulation is a compatibility test, not physical-device performance. Actual native picking/shaders/lifecycle remain a release gate. The generated concept was not installed/inspected due Library helper download failure, and no reference image is used as a backdrop. Architecture quality still needs user/parent review.

# Transit diorama integration

Branch `codex/8-transit-art` starts at transit engine `eb2e88c`. Local preparatory commits `1deacc9` and `1851ea0` reproduce previously delivered graphics `517e23f` and `b6237a1`, resolving transit-map draft and infrastructure call conflicts. **Do not cherry-pick those preparatory commits if the main integration already has their originals.** Apply only the final transit-art commit onto a branch containing transit engine plus prior graphics; regenerate the bundle. No engine algorithms were edited.

Original models now include a multi-bay transit works depot, articulated elevated platform canopy/rails/stairs, concrete piers and paired guide rails. Guideway geometry is cached by track array, revision and world size. No hard-coded world dimensions, parcel clearing or water crossing is introduced: geometry follows the engine's existing public road rights of way. Bus stop poles use the actual configured stop cells.

Viaduct decks and piers are now static scene objects sharing depth order with buildings; moving buses and metro sets participate in the normal clipped actor/foreground compositor. The old separate transit vehicle draw is removed, avoiding duplicate vehicles. Night emission also masks against guideway geometry, so rear windows do not shine through concrete. Vehicle art uses a common projected plane with wheels/bogies, cream bodies, route liveries, glazing, roof equipment, head/tail lights, and a load-dependent amber destination marker. This marker reflects daily paid load, not a literal individual boarding event.

Pure visual corner sampling rounds the engine's route positions without any route search or change to capacity, fare or economic settlement. Depot apron markings do not invent stored fleet. Samples return before the engine pose API at distant zoom, disabled traffic or reduced motion. Near samples are viewport culled and capped48; station/infrastructure geometry remains visible at overview zoom with supports culled below0.38. Terminal reversing remains the engine's stylized shuttle reversal; literal timetables/individual boarding are not claimed.

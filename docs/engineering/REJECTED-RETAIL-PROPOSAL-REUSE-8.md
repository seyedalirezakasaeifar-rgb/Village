# Rejected proposal-local worker reuse

This branch is experimental and must not be cherry-picked into production. Six warmed alternating baseline/candidate pairs each advance the same retained late town 180 days. All final canonical model/RNG states match exactly; direct bids also match after same-day wage, closure, public-duty, search-delay, minimum-wage, home and day mutations. The candidate holds worker/wage inputs only within one atomic retail proposal; it adds no persistent cache.

However only three of six model timings improve and median whole-model time is essentially unchanged. Safety alone is insufficient evidence of a useful optimization. Candidate changes to 27-urban-evolution and 29-retail-labour are rejected. Source-bound receipt and reproducible test remain here; production keeps the original implementation. This is not proof of smoothness or an improvement in frame/input latency.

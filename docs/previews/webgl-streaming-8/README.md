# Camera-driven bounded world streaming and geometry LOD

The renderer now selects actual world cells from four ground-plane camera corners, adds a four-cell silhouette/shadow margin and quantizes selection to8tile boundaries. Pan/zoom/viewport changes rebuild only when that selection or near/mid/far geometry band changes. The last scene is disposed, not retained in an expanding cache; renderer/context/canvas and stable building identities survive. Ground covers the real128atlas; distant districts are no longer permanently omitted by a town-hall radius. No ownership or construction authorization changes.

Near uses full trim and five detailed tree crowns. Mid suppresses subpixel trim and uses three low-poly crowns; far suppresses fine trim and uses one low-poly crown. Trees now use two instanced meshes rather than one geometry/material per trunk/crown. Production preview warmup is three frames then dirty-only; benchmark mode explicitly requests90frames. Actor suppression/bridge/remaining-specialized work follows separately; it is not claimed here.

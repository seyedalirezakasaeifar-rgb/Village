# Development checkpoint

`TownLedger-Android.apk` is a standalone installable APK for game source `129be0f`. It is an intermediate development checkpoint, not the final overnight delivery or a store release.

The source ZIP contains matching game code/assets, tests and text QA. Repository screenshots remain in the documentation galleries. Private signing keys, private logs and personal saves are excluded.

See `manifest.json` for hashes and validation. The APK uses the persistent development signer; it differs from the original baseline signer. Preserve a verified town export before any uninstall required by Android. Native input, document picker and lifecycle playtests remain pending for this checkpoint.
